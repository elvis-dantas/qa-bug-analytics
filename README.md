# 📊 QA Metrics & Bug Analytics
Projeto de análise de métricas de qualidade de software utilizando Python,
análise exploratória, Machine Learning e dashboard interativo.


## 🚀 Tecnologias
- Python
- Pandas
- Seaborn
- Scikit-learn
- Streamlit


## 📈 Funcionalidades
- análise exploratória;
- métricas de qualidade;
- dashboard interativo;
- visualização de bugs;
- previsão de tempo de correção.


## 🧠 Insights
- maior quantidade de bugs críticos em produção;
- APIs possuem maior reincidência;
- aumento de falhas após novas releases.

- módulos com maior número de falhas;
- tempo médio de correção;
- severidades mais recorrentes;
- bugs críticos em produção;
- evolução mensal de bugs;
- reincidência de defeitos.
